# 🌍 AI Powered Trip Memories

A personal travel memory application to save, organize, and relive beautiful travel experiences with the power of Generative AI.

## ✨ Features
- Add and manage travel destinations.
- Save trip details and personal memories.
- Upload travel photos.
- Interactive chat interface for future AI-powered memory assistance.

## 🛠️ Tech Stack
- **Frontend:** React.js, CSS
- **Backend:** Python, FastAPI
- **Database:** MySQL
- **AI (Planned):** LangChain, LLMs, RAG, ChromaDB

## 🚀 Project Status
Currently under development. Building step by step, with more exciting AI features coming soon!
